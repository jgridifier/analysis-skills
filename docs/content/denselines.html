The short version

  • What it is. A density view of many overlapping short series: each series is rasterised, normalised by its own arc length, and added, so ink shows how many series pass through a pixel rather than how wiggly the noisiest ones are.
  • Status: promoted (Jared, 2026-11-13, 11:51 PM ET). Teaching page: 2026-11-13 scout, method 2. Approval: APPROVAL.md.
  • Novelty: obscure. A visualization paper with a small Rust reference implementation, not a standard statistical package.
  • Evidence limit: Stage 2–3 on this repo's real panels has not been run. Pixel-level parity with the authors' Rust reference was recorded on the scout (max relative difference 2.1e-7) and was not re-run at promotion (that would have required a Rust build). The gap-case invariants were replayed.
01

Citations

Moritz, D. & Fisher, D. (2018). "DenseLines: Efficient Many-To-One Context Preservation in Line Chart Visualizations." arXiv:1808.06019.
Authors' Rust reference: github.com/domoritz/line-density-rust @ 083890c. The supported implementation here is a NumPy port in skills/run-line-density-chart/scripts/line_density.py, checked against that reference on the scout. No neural nets.

02

The math, plainly

Each series is drawn onto a canvas with a Bresenham rasteriser (the reference uses imageproc's iterator: a pixel is set to 1, not incremented, so shared endpoints count once). The binary image is then divided, column by column, by that series' own column sum — arc-length normalisation — and the normalised images are summed. A column's ink is therefore "how many series pass here," not "how much ink the jumpy ones spilled." If any series does not cover a column, the reference does 0/0 and writes NaN, which poisons that whole column of the aggregate. The port's gap_safe=True extension treats uncovered columns as 0 instead. Use that flag whenever start or end dates are staggered.

03

Why it is unusual, and fast

  • The normalisation is the unusual part: it is a small, inspectable alternative to "plot all the lines and hope."
  • The Rust reference is fast; the NumPy port matches it closely (max relative difference 2.1e-7 on 5,000 series) and is 10–120× slower. The 50,000-series speed step ran out of memory on the scout and was never finished.
  • A residual brush can point at a hidden group (94% recall, with a keyword, of a planted AI-demand cluster on the Corning mock) but is bandwidth-fragile.
